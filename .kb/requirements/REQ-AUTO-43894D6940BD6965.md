Runner must run mutants in child processes, not threads, loading the project once per worker.

## Context

Tests under mutation can write temp directories, spawn processes, and exhaust the stack or heap; process isolation contains that.

## Source

> The first draft uses child processes and pays the load cost once per worker, not once per mutant.
