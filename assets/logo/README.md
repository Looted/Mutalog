# Mutalog logo

The mark is a lowercase *m* whose full stop has jumped out of line: a
Prolog clause with its terminating `.` mutated.

| File | Use |
| --- | --- |
| `mutalog-logo.svg` | Mark and wordmark, for light backgrounds |
| `mutalog-logo-dark.svg` | Mark and wordmark, for dark backgrounds |
| `mutalog-mark.svg` | Mark only, for light backgrounds |
| `mutalog-mark-dark.svg` | Mark only, for dark backgrounds |
| `mutalog-mark-512.png`, `mutalog-mark-dark-512.png` | Transparent PNGs of the mark, 512 × 512 |
| `favicon.svg` | Mark that follows the viewer's light or dark colour scheme |

## Colours

| | Light background | Dark background |
| --- | --- | --- |
| Ink | `#1f2147` | `#ecebfa` |
| Mutation (the dot) | `#d6336c` | `#ff6b9d` |

The wordmark is IBM Plex Mono SemiBold (SIL Open Font License),
converted to outlines so the SVGs need no font.
